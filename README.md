# Задачи (sbe-tasks)

SBE-плагин «Задачи» — модуль «Задачи» YouGile, вынесенный из монолита
`yougile-tntn`. Список задач, дерево подзадач, фильтры, детали с чатом,
создание и редактирование.

## Требования

- Установлены и включены: `sbe-apstore` (ЦУП СБЕ ПМиПИР), `sbe-yougile`.
- В `sbe-yougile` выполнена авторизация (логин/пароль/companyId → «Получить ключ»).

## Использование

Откройте плагин через ЦУП СБЕ ПМиПИР → «Установленные» → «Открыть» (у sbe-tasks
собственных риббона и команд нет).

## Возможности

- Список задач с фильтрами (проект, доска, колонка, исполнитель, статус),
  поиском и деревом подзадач.
- Детали задачи: описание, исполнители, подписчики чата, дедлайн, чек-листы,
  учёт времени, чат задачи с файлами, «Дополнить описание».
- Создание и редактирование задач.
- Офлайн-очередь: действия при отсутствии сети сохраняются и синхронизируются.
